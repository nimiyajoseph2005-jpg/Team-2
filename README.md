# HR-AI Resume Intelligence System
AI-powered HR Resume Intelligence System that automates resume screening using Gemini AI. The system extracts resume text, compares candidates with job requirements, generates scores and verdicts, displays analytics dashboards, and provides an AI chat interface for candidate exploration and analysis.

## Overview

HR-AI Resume Intelligence System is an AI-powered resume screening platform developed using Python, Streamlit, and Gemini AI.

The system helps HR teams automate resume analysis by extracting resume content, comparing candidates with job requirements, generating scores and verdicts, and displaying results through interactive dashboards.

It also includes an AI-powered chat feature for exploring candidate details.
